# Pet AI Content Factory 依赖说明
#
# 依赖说明。主项目依赖由 MoneyPrinterTurbo v1.3.10 的 pyproject.toml / uv.lock 提供；
# 以下 4 个「豆包 + 本地」能力所需的小依赖需要额外安装（已装入 .venv）：
#
#   pyautogui>=0.9      -> doubao_desktop_service / doubao_script_service（操作豆包客户端）
#   pyperclip>=1.8      -> 从剪贴板取回豆包回复的 JSON
#   pywin32>=306        -> sapi_tts_service（Windows SAPI5 离线配音）
#   soundcard>=0.4      -> 仅历史排查豆包回环录音时用过；默认流程不需要，可不装
#
# 主项目已有：
#   openai>=2.24        -> deepseek_service（仅在手动启用付费 API 时使用）
#   toml>=0.10          -> config/settings.py
#   imageio-ffmpeg>=0.6 -> 本地 FFmpeg：配音音量处理 / 图片转视频 / 时长对齐
#   faster-whisper>=1.1 -> subtitle_service 的可选 whisper 字幕（本地模型）
#   moviepy==2.2.1      -> 通过复用 MPT 合成引擎间接使用
#   pytest>=9           -> PetAI 测试（原项目 dev 依赖组已包含）
#
# 安装方式（在项目根目录执行，与原项目共用同一环境）：
#   uv sync --frozen
#   .venv/Scripts/python.exe -m pip install pyautogui pyperclip pywin32
#
# 完全不需要安装：Piper、CUDA、任何付费 SDK。默认方案不需要 API Key。
