## Pet AI Content Factory V1.0 改造 — 阶段 1 项目审计（只读，未改代码）

### 背景
用户提供完整任务书：基于现有 MoneyPrinterTurbo v1.3.10 做低成本改造，做面向猫狗创作者的
Pet AI Content Factory。核心原则：DeepSeek 为唯一默认付费 AI；默认关闭 AI 图片/视频生成、
在线 TTS；本地素材+本地 TTS+FFmpeg 优先；付费服务调用前必须用户确认，不允许静默回退。

### 审计确认的关键事实
- 版本 v1.3.10（pyproject.toml:10 / app/__init__.py:3）。Python>=3.11。依赖用 uv.lock 锁定。
- 当前激活配置（config.toml）：llm_provider=moonshot(:81)、video_source=pexels(:26)、
  script_generation_backend=local(:17)、subtitle_provider=edge(:226)、enable_redis=false(:229)。
- DeepSeek provider 已内置：app/models/llm_provider.py:330 id=deepseek，默认模型 deepseek-v4-pro，
  base_url=https://api.deepseek.com；配置项 deepseek_api_key/base_url/model_name 在 config.example.toml:513-516。
  无需新增 provider，只需切 llm_provider=deepseek 并填 key。注意模型名以官方当前可用为准，不要写死。
- LLM 框架：openai SDK 为主（app/services/llm.py:14），litellm 只是一个 adapter。配置无 [llm] 区块，
  全部在 [app] 段，字段 {provider_id}_api_key。
- 付费面：46 个 LLM provider；AI 图（openai_image/codex_image/useapi_image）；AI 视频
  （volcengine_seedance/jalapeno/ofox/muapi/useapi/metaso_minimax/infistar/wavespeed/loomloom）；
  配乐（sonilo/elevenlabs_music）；语义（twelvelabs）；TTS 11 种。开关集中在 config.toml [app]。
- 好消息：**不存在主服务失败自动切换其他付费 provider 的逻辑**（重试固定同一 provider）。
  已有"禁止静默切付费"的先例：edge 字幕失败禁止自动切 whisper（task.py:697-705）。
- 成本统计：项目完全没有 token/费用记录。request_logging.py 只记状态和耗时，不读响应体。
  唯一费用日志是 aigei.py:286 铜币结算。需从零新建成本模型与埋点。
- 本地 TTS：无 piper/coqui。最接近零成本的是 Edge TTS（免费云端，非本地）、自托管
  Kokoro/Chatterbox（本地 HTTP 服务）。需新增 Piper adapter。
- 视频合成：app/services/video.py:1635 generate_video(video_path,audio_path,subtitle_path,output_file,params,bgm_file_override)。
  主流程 task.py:1570-2030 _run_pipeline()：脚本→搜索词→TTS→字幕→素材→合成→发布。
  **默认即 9:16 竖屏**（schema.py:114 VideoAspect.portrait → 1080x1920）。video.py 无 logo/水印支持，
  需新增图层参数。
- 任务状态：内存 dict 或 Redis（enable_redis 切换），默认内存重启即失。无真正取消运行中任务机制。
- WebUI：Streamlit 单页 webui/Main.py，入口 _render_application()（约 :4570+）。新增宠物模块建议
  顶层 st.tabs 或顶栏按钮+st.dialog。i18n 在 webui/i18n/zh.json + en.json 的 Translation 节点。
- API：FastAPI 在 app/asgi.py:264 get_application()；路由聚合 app/router.py；新增路由用
  app/controllers/v1/base.py 的 new_router() 再 include 到 router.py。
- 存储：无 SQLite/数据库。全是文件+内存/Redis：task_artifacts.py 用原子 JSON 写 script.json，
  material_cache.py 用带 TTL 的 JSON 缓存。宠物系统需新建轻量 SQLite（stdlib sqlite3 即可）。
- 启动：Windows 双击 webui.bat（streamlit run webui/Main.py）。测试 pytest（test/ 约 279 个文件），

### 新增文件（PetAI/ 独立包）
- config/settings.py：配置加载。付费服务默认全关，DeepSeek+本地TTS开，本地素材优先。
  Key 只读环境变量/.env，公共视图脱敏，占位符视为未配置。价格表从 petai.toml 读不写死。
  **坑：_deep_merge 必须 deepcopy(base)，否则默认 dict 被实例修改污染（测试抓到）**
- config/petai.example.toml：配置模板（含可配置价格表 CNY/1M tokens）
- .env.example：DeepSeek Key 模板（.env 已 gitignore）
- database/database.py：标准库 sqlite3，线程局部连接，WAL 模式，cost_records/service_checks 两表
- utils/safe_log.py：日志脱敏过滤器，sk- 前缀与已知 Key 字面量替换
- services/cost_service.py：CostGuard 付费闸门。require() 是唯一入口，关闭/缺Key直接抛错；
  assert_no_fallback() 强制禁止回退；计价走配置价格表，无价格则标记估算；任务/月/累计费用统计。

- services/local_asset_service.py：本地素材上传(不覆盖同名/不删原件)、分类/搜索/标签、本地优先选取、
  使用次数统计、网络素材闸门
- app/bootstrap.py + cli.py：依赖装配 + init/status/test-deepseek 命令
