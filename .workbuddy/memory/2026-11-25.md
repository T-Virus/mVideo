## 阶段 4 本地生产系统（已完成，56 测试全过）

### MPT 核心接口审计结论（关键，供后续复用）
- `video.generate_video(video_path, audio_path, subtitle_path, output_file, params, bgm_file_override)`：
  **接受的是文件路径**，只要 PetAI 产出「合成好的无声素材视频+音频+SRT」即可复用，不改 MPT 核心。
- `video.combine_videos(combined_video_path, video_paths, audio_file, video_aspect, video_concat_mode, max_clip_duration, ...)`：
  把本地图片/视频路径拼成无声视频；对本地任意路径图片会自动清理 EXIF，兼容本地素材。
- `VideoParams.video_aspect=VideoAspect.portrait` → 默认就是 **1080×1920 / 9:16**。
- `app.utils.utils.get_ffmpeg_binary()`：统一 ffmpeg 解析（PATH→imageio-ffmpeg 内置二进制，本项目内置可用）。
- `voice.tts()` 走 edge/azure/elevenlabs 等**在线付费**链路 → PetAI 绝不调用它。
- `subtitle.create()` 用 faster-whisper 本地模型；`subtitle_provider=edge` 失败时 MPT 已有「禁止自动切 whisper」先例。

### 环境事实
- Piper 未安装、系统 PATH 无 ffmpeg；但 imageio-ffmpeg 内置二进制、faster_whisper、moviepy、字体、BGM 均可用。
- 因此默认走「上传配音兜底」；Piper 需用户自行安装+下载模型后填 petai.toml。
